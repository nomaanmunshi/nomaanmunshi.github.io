Personal portfolio: https://nomaanmunshi.github.io/

## Development

Static HTML, CSS and JavaScript, deployed with the existing GitHub Pages setup. No build step or runtime packages.

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. `index.html` owns the content, `styles.css` owns the responsive design and theme tokens, and `script.js` handles theme selection and accessible navigation. The early inline theme initializer prevents a wrong-theme flash and preserves the existing `nomaan-theme` preference.
